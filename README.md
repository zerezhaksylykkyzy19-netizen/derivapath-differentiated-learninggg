# DerivaPath — Differentiated Derivatives Practice

A responsive calculus practice website with three separate task banks and a **Generate new task** button.

## Features
- Foundation, Standard, and Advanced levels, each with different tasks.
- Generate new task chooses from the current level's task bank.
- Each task has its own hint and step-by-step explanation.
- Answer checking with immediate feedback.
- Responsive layout for desktop and mobile.

## Run locally
Open `index.html` in a browser.

## Publish with Netlify Drop
1. Extract this ZIP.
2. Open the `DerivaPath_Improved` folder. `index.html`, `styles.css`, and `app.js` should be directly inside.
3. Drag that folder onto https://app.netlify.com/drop.

## Important AI integration note
This deliverable uses prepared task banks and local rule-based answer checking. It does not yet make live AI API calls. If the assignment requires a live AI API, add a secure server-side endpoint and store the API key in environment variables; never expose a private API key in browser JavaScript.
